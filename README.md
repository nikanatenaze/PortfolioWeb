## 📌 Overview

This project was an early iteration of my personal developer portfolio, designed to showcase my software engineering projects, technical skills, background, and personal contact links in a clean, responsive web interface.

## 🛠️ Features & Technologies

- **Frontend:** HTML5, CSS3, Type Script
- **Interactivity & Design:** 3D model integration, custom CSS styling, and responsive layout design
- **Sections Included:**
  - **About Me:** Overview of background, education, and interests
  - **Projects:** Highlights of algorithmic work, API services, and web apps
  - **Contact & Socials:** Direct links to GitHub, LinkedIn, and email
